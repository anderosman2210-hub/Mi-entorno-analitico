# Mi entorno analítico

## Objetivo

El objetivo de esta actividad fue instalar y configurar las herramientas necesarias para comenzar a trabajar en análisis de datos. Durante el proceso instalé Anaconda, exploré Jupyter Notebook y realicé una primera ejecución utilizando Python y Pandas.

## 1. Instalación de Anaconda

Instalé Anaconda en mi computadora para tener acceso a Python y a diferentes herramientas que vamos a utilizar durante el curso.

Durante la instalación aprendí que Anaconda permite tener varias herramientas relacionadas con análisis de datos en un mismo entorno, lo cual facilita su instalación y administración.

## 2. Exploración de Anaconda Navigator

Después de completar la instalación exploré Anaconda Navigator. Desde esta aplicación pude encontrar y ejecutar Jupyter Notebook.

Aprendí que Navigator funciona como una interfaz gráfica que permite acceder a diferentes herramientas y administrar el entorno de trabajo.

## 3. Exploración de Jupyter Notebook

Abrí Jupyter Notebook y creé mi primer notebook. Aprendí que Jupyter permite escribir y ejecutar código de Python utilizando celdas.

Durante la configuración también tuve un problema al iniciar el kernel. Esto me permitió entender que el kernel es el proceso que se encarga de ejecutar el código dentro del notebook.

## 4. Primera ejecución de código

Para comprobar que el entorno funcionaba correctamente, utilicé Pandas para crear una pequeña tabla con nombres, edades y notas.

Al ejecutar correctamente el código pude comprobar que Python, Pandas y Jupyter Notebook estaban funcionando.

## Aprendizajes

Con esta actividad aprendí a instalar y acceder a Anaconda, utilizar Anaconda Navigator, crear un notebook en Jupyter y ejecutar código básico de Python. También aprendí a identificar y corregir errores básicos de sintaxis y a comprobar que el entorno está correctamente configurado.

## Conclusión

Después de completar el proceso tengo configurado un entorno básico para comenzar a trabajar con análisis de datos durante el curso.
